특수 효과, 무엇을 가리킬까요?

특수 효과란?
게임, 영화 등의 미디어에서 사용되는 공감각적 효과예요.
보통 현실 세계에서의 경험을 강조하고 부각시키는 용도로 사용해요.
게임에서 특수 효과는?
시청각적 품질과 현실감을 제고하여 몰입감 증대 >>> 재미 증대로 이어져요.
부자연스러운 것을 가리기 위해서도 사용해요.

특수 효과의 네 가지 갈래

✨
파티클 시스템
작은 이미지를 여러 개 뿌려 불 · 연기 · 눈 같은 효과를 만들어요.
🔆
물리 기반의 렌더링
빛이 실제 재질에 부딪히는 방식을 흉내 내 표면을 사실적으로 보여줘요.
💡
라이팅과 쉐이딩
빛과 그림자로 입체감과 분위기를 만들어요.
🎞️
포스트 프로세싱
화면이 다 그려진 뒤, 색감 · 흐림 같은 후처리를 더해요.

파티클 시스템이란?

파티클 시스템이란?
이미지나 모델(Particle)을 사용하여 시각적 효과를 생성하는 시스템이에요.
불 / 연기 / 물 / 눈 등 다양한 효과 연출이 가능해요.
좋은 파티클 (특수 효과)
화려한 것 ( X ) → 자연스러운 것 ( O )
너무 화려하게 꾸미기보다, 그 장면에 자연스럽게 녹아드는지를 먼저 봐요.

오늘 쓸 것

Shuriken (Particle System)

참고로만 알아둘 것
🧩
VFX Graph
GPU 기반, 노드를 선으로 연결해서 만들어요. 수십만 개 단위의 입자도 다룰 수 있지만, 별도 패키지 설치가 필요해요.
오늘은
기본 내장된 Shuriken으로, 모듈 하나하나가 어떤 역할을 하는지부터 익혀요. VFX Graph는 이 개념 위에서 규모만 키운 버전이라, 오늘 익히는 개념이 그대로 통해요.

파티클 시스템 만들기

STEP 1
에디터 메뉴 / 인스펙터
GameObject → Effects → Particle System으로 추가하고 Inspector를 열어요.
→
STEP 2
파티클 시스템 모듈 추가
Inspector의 체크박스를 눌러 필요한 모듈(Shape, Color over Lifetime 등)을 켜요.
→
STEP 3
파티클 설정
켠 모듈 안의 값을 조정하며 원하는 모양과 움직임을 만들어요.
기억해둘 것
모듈은 필요한 것만 켜서 써요. 다 켠다고 좋은 효과가 되진 않아요 — 앞서 본 "자연스러움"의 기준을 떠올려요.

파티클 시스템, 전체 구조로 보면

모듈역할
Main
(항상 켜짐)		Duration · Looping · Start Lifetime/Speed/Size/Color 등, 입자 하나하나의 기본값을 정해요.
Emission얼마나 자주, 몇 개씩 태어날지 정해요.
Shape어떤 모양의 영역에서 태어날지 정해요.
Velocity over Lifetime수명 동안 속도가 어떻게 바뀔지 정해요.
Limit Velocity over Lifetime속도의 최대치를 제한해요.
Inherit Velocity이미터(부모)의 속도를 입자가 물려받게 해요.
Lifetime by Emitter Speed이미터 속도에 따라 입자 수명을 조절해요.
Force over Lifetime중력 외에 추가 힘(바람 등)을 줘요.
External Forces씬의 Wind Zone 같은 외부 힘을 받게 해요.
Noise움직임에 불규칙함을 더해요 — 연기 · 불처럼.
Collision바닥 · 벽에 부딪혔을 때 반응을 정해요.
Triggers지정 영역 출입을 감지해 콜백을 호출해요.
모듈역할
Color over Lifetime수명 동안 색이 어떻게 바뀔지 정해요.
Color by Speed속도에 따라 색이 바뀌게 해요.
Size over Lifetime수명 동안 크기가 어떻게 바뀔지 정해요.
Size by Speed속도에 따라 크기가 바뀌게 해요.
Rotation over Lifetime수명 동안 회전하게 해요.
Rotation by Speed속도에 따라 회전 속도가 바뀌게 해요.
Sub Emitters특정 순간(Birth · Death 등)에 새 파티클을 만들어요.
Texture Sheet Animation텍스처 프레임을 순서대로 넘겨 애니메이션처럼 보여요.
Lights입자마다 실제 광원을 붙여요.
Trails입자가 지나간 자리에 궤적(꼬리)을 남겨요.
Custom Data셰이더에 전달할 커스텀 값을 저장해요.
Renderer
(항상 켜짐)		입자를 화면에 어떻게 그릴지 정해요. 끌 수 없어요.

Simulation Space, Local일까 World일까?

📦
Local
파티클이 이미터(부모)를 계속 따라가요. 캐릭터 손에 붙은 마법 이펙트처럼, 발사체와 함께 움직여야 할 때 써요.
🌍
World
태어난 자리에 그대로 머물러요. 빗방울이나 불꽃놀이처럼, 쏜 사람이 움직여도 입자는 그 자리에 남아야 할 때 써요.
자주 하는 실수
Local로 두고 이미터를 움직이면, 이미 태어난 입자까지 같이 끌려와요. 뒤에서 볼 Rain Drop · Fireworks는 둘 다 World를 써요.

만들어보자 #01 — Rain Drop

Scene · PlayRainy

Rain

Start Speed10~15
Start Lifetime1~2s
Gravity Modifier0.5~1
ShapeBox (넓고 얇게, 위쪽)
Render ModeStretched Billboard
Length Scale2~4
Rate over Time50~100
Simulation SpaceWorld

Rain Drop, 자연스럽게 다듬기

① 화면을 가득 채우나요?Shape(Box)의 크기를 카메라가 보는 범위에 맞게 넓혀요.
② 빗줄기가 선처럼 보이나요?Length Scale과 Start Speed를 같이 조정해 길이를 맞춰요.
③ 바닥에 닿으면 어떻게 되나요?Collision을 켜거나, 바닥용 작은 파티클(물결)을 따로 만들어 겹쳐요.
④ 너무 쏟아지진 않나요?Rate over Time을 낮춰보고, 화려함보다 자연스러움을 기준으로 비교해요.

만들어보자 #02 — Fireworks

Scene · PlayFireworks
1단계 · 발사
Launch 파티클
아래에서 위로 한두 개씩, Gravity로 포물선을 그리며 올라가요.
→
2단계 · 폭발
Sub Emitter
Launch 파티클이 사라지는 순간(Death), 그 자리에서 새 파티클을 터뜨려요.
→
3단계 · 잔상
Color / Trail
Color over Lifetime로 점점 사그라들고, Trail로 궤적을 남겨요.
참고
실제 불꽃놀이 영상을 잠깐 보고, 발사 → 정점 → 폭발 → 사그라듦의 타이밍을 눈으로 익혀봐요.

Fireworks 설정 디테일

Fireworks

Start Speed (Launch)8~12
Start Lifetime (Launch)1~1.5s
Gravity Modifier1
EmissionBurst 1~2개
Sub EmittersBirth = Death
Shape (Explosion)Sphere
Start Speed (Explosion)3~6 (방사형)
Color over Lifetime밝게 → 투명하게

Sub Emitters, 네 가지 트리거

트리거언제 새 파티클이 태어날까요
Birth부모 입자가 태어나는 순간 — 발사 직후 연기 꼬리처럼
Collision부모 입자가 뭔가에 부딪히는 순간 — 빗방울이 바닥에 튀는 효과처럼
Death부모 입자가 수명을 다하는 순간 — Fireworks의 폭발처럼
Trigger지정한 영역에 들어오거나 나갈 때 — 특정 구역 통과를 감지할 때
더 만들어보고 싶다면
Death에 Birth를 하나 더 얹으면, 폭발하면서 동시에 반짝이는 잔불까지 — 레이어를 겹쳐볼 수 있어요.

파티클이 안 보일 때

① Play On Awake가 꺼져있나요?껐다면 코드로 직접 Play()를 호출해야 해요.
② Start Lifetime이 0은 아닌가요?태어나자마자 바로 사라지고 있을 수 있어요.
③ Max Particles가 너무 작진 않나요?Emission보다 작으면 입자가 더 못 태어나요.
④ Renderer의 Material이 비어있진 않나요?모양은 있는데 눈엔 안 보이는 가장 흔한 원인이에요.

오늘, 기억할 것들

✓Shuriken은 CPU 기반 내장 시스템, VFX Graph는 GPU 기반 노드 시스템 — 오늘은 Shuriken으로 개념을 익혔어요.
✓좋은 파티클은 화려함보다 자연스러움이 먼저예요.
✓Emission(얼마나) · Shape(어디서) · Renderer(어떻게)가 Particle System의 기본 뼈대예요.
✓Simulation Space는 World/Local — 이펙트가 발사체를 따라가야 하는지부터 정해요.
✓Sub Emitters로 파티클이 사라지는 자리에서 새 파티클을 또 터뜨릴 수 있어요 — Fireworks의 핵심이에요.
