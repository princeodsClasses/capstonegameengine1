답이 이상해요.
증상
"이상하게 작동해요", "바꿔줘요", "수정요망" 등.. 이렇게 질문이나 요구를 하면? AI 가 엉뚱한 곳을 고칠 수 있어요.
결국 처음부터 다시 설명해야 해요.
그리고, 이렇게 접근하면 결과적으로 더 많은 토큰을 사용하고, 시간도 더 오래 걸려요.
그러면 어떻게 해요?
질문이나 요구가 명확해야 해요.
육하원칙 알죠? AI 도 명확하고 구체적으로 지정해주기를 바라요.
같은 “멈춤”이라도 버튼 입력, 씬 로딩, 화면 갱신 중 어디서 문제가 생겼는지에 따라 볼 코드가 달라요.
재현 순서와 로그가 있으면 확인할 범위를 좁힐 수 있어요.
수정하려는 곳(파일)을 특정하는 것도 좋은 방법이에요.

오류를 어떻게 해야 해요?

대표적인 오류들.

Compile-time Error
실행도 안 돼요
컴파일 단계(실행 이전)에서 발생해요. 발생하면 아예 플레이되지 않고, 유니티·IDE 콘솔에서 바로 정보를 보여줘요.
Run-time Error
실행 중에 멈춰요
실행 중 실시간으로 발생해요. 해당 스레드에서 진행 중이던 이후 동작이 중단되고, 유니티 콘솔에서 정보를 보여줘요.
Logic Error
에러 >> 버그
에러가 아니라 버그예요. 콘솔에 안 뜨니까 찾기 어렵고, 무한 루프면 애플리케이션이 아예 반응하지 않아요.
"에러"가 뜬다는 건 사실 친절한 편이에요 — 가장 어려운 건 조용히 틀리게 동작하는 Logic Error예요.

Compile-time Error

① Syntax Errors코드의 문법·구조를 다르게 사용해 발생 (세미콜론 누락, 괄호 안 닫힘 등)
② Type Mismatch변수 타입에 안 맞는 값을 대입. "Cannot implicitly convert type 'string' to 'int'"
③ Undeclared Variables선언 안 된 변수를 사용. "The name 'x' does not exist in the current context"
④ Method Signature Mismatch메서드 인자가 일치하지 않음. "No overload for method takes 'n' arguments"
⑤ Access Modifier Errors접근 제한자 범위를 잘못 지정·사용. "Inconsistent accessibility"
⑥ Constant Value Errors상수(const)에 실행 중 계산되는 값을 할당. "A constant value is expected"
⑦ Inheritance Errors인터페이스 상속 후 메서드 미구현. "does not implement interface member"
⑧ Overload Problems동일 인자로 메서드를 중복 정의. "Member 'Name' is already defined"

Run-time Error

① NullReferenceException선언만 되고 할당되지 않은 값에 접근할 때
② ArgumentOutOfRangeException배열·리스트의 범위를 벗어난 인덱스로 접근할 때
③ InvalidOperationExceptionforeach로 순회 중인 컬렉션을 그 안에서 변경할 때
④ DivideByZeroException값을 0으로 나누려 할 때
⑤ FormatException / InvalidCastException문자열 파싱이나 형변환이 불가능할 때
⑥ ArgumentNullExceptionnull이 들어오면 안 되는 자리에 null 인자를 넘길 때
⑦ StackOverflowException무한 재귀 호출로 스택 메모리가 넘칠 때

증상
에이전트가 제시한 코드를 붙여넣었더니 돌아가긴 해요. 그런데 왜 되는지 설명을 못 해요.
왜 안 풀릴까요
한 번 실행됐다는 사실만으로는 어떤 변경이 문제를 해결했는지 알기 어려워요. 다른 씬이나 같은 버튼을 두 번 눌렀을 때도 동작을 확인해야 할 수 있어요.
대처법 — 바뀐 코드와 수정 이유를 조원에게 한 문장으로 설명해요. 수정 전후에 같은 절차를 실행하고, 영향을 받는 기존 동작도 확인해요.
