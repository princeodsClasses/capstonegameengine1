BGM은 키로 요청해요.

장면의 상태가 바뀌는 시점
AudioManager.Singleton.PlayBGM("Calm");

// 전투 진입이 확정됐을 때
AudioManager.Singleton.PlayBGM("Battle");

// 즉시 전환하고 비교하기
AudioManager.Singleton.PlayBGM("Calm", 0f);

// 침묵도 연출이에요.
AudioManager.Singleton.StopBGM();
같은 곡은 처음부터 다시 틀지 않아요
같은 키가 재생 중이면 요청을 무시해요. Update에서 매 프레임 호출하지 말고 상태 변화에 연결해요.
기본 전환은 1초
새 곡과 이전 곡을 두 채널에서 겹쳐요. 무조건 부드러운 전환이 정답인지도 비교해봐요.

두 채널로 교차 전환해요.

음량의 역할을 나눠요
테이블의 기본 음량 × 사용자 BGM 음량 × 전환 계수. 전환 중 슬라이더를 바꿔도 사용자 설정을 반영해요.

SFX는 사건이 확정된 순간에

명중 처리에서 호출
// 화면 전체에서 들리는 2D 효과음
AudioManager.Singleton.PlaySFX("Hit");

// 실험: 명중보다 0.3초 늦게
AudioManager.Singleton.PlaySFX("Hit", 0.3f);

// 맞은 지점에서 들리는 3D 효과음
AudioManager.Singleton.PlaySFX3D("Hit", hitPoint);

// 지연 예약까지 취소
AudioManager.Singleton.StopSFX();
공격 입력과 명중 결과를 구분해요
이번 예제는 단발 SFX를 재생해요. 3D 모드는 테이블의 delay와 거리 설정을 사용해요.
빈 채널을 재사용해요
지연 재생도 채널을 예약해요. 채널이 가득 차면 기존 소리를 끊는 대신 새 요청을 생략하고 경고해요.

음량과 무음을 따로 조절해요.

Slider / Toggle과 연결할 공개 함수
AudioManager.Singleton.SetBgmVolume(0.5f);
AudioManager.Singleton.SetSfxVolume(0.8f);

// 일시적인 전체 무음
AudioManager.Singleton.SetMuted(true);
AudioManager.Singleton.SetMuted(false);
음원별 음량을 유지해요
사용자 SFX 볼륨을 바꿔도 각 효과음의 테이블 volume 비율은 유지해요.
Audio Mixer는 선택 연결
Manager의 Bgm Output / Sfx Output에 그룹을 연결하면 라우팅할 수 있어요. 기본 실습은 Mixer 없이 동작해요.
